# Favicon & App Icons

This folder contains all the PNG favicon and app icons used across the entire website and web manifest.

## Files & Sizes

- **`favicon-16x16.png`**: Standard browser tab favicon (16×16 px PNG)
- **`favicon-32x32.png`**: Standard desktop tab favicon (32×32 px PNG)
- **`favicon-48x48.png`**: High-DPI browser favicon (48×48 px PNG)
- **`apple-touch-icon.png`**: iOS home screen bookmark icon (180×180 px PNG)
- **`android-chrome-192x192.png`**: Android PWA / home screen icon (192×192 px PNG)
- **`android-chrome-512x512.png`**: Android high-resolution splash/PWA icon (512×512 px PNG)
- **`favicon.ico`**: Legacy browser multi-resolution icon (16, 32, 48 px)
- **`icon-1024x1024.png`**: Master full-resolution icon (1024×1024 px PNG)

## How to Update Icons in the Future

To update or replace any of these icons:
1. Upload your new PNG image directly into this `favicon-icons/` folder using the file explorer.
2. Keep the exact same filenames listed above.
3. All web pages, tabs, bookmarks, and mobile PWA manifests will instantly display your new icon!
